# منصة الواحة الرقمية للعوينة 2026

منصة ويب رقمية في إطار مشروع **العوينة سوس 2026**، تهدف إلى دعم البنية التحتية للواحة، والاستدامة الفلاحية، وبناء المجتمع المحلي.

## الأهداف

- **البنية التحتية للواحة**: توثيق وتتبع مرافق الواحة وحاجياتها.
- **الاستدامة الفلاحية**: إبراز المبادرات التي تحافظ على الواحة وتنمّي إنتاجها.
- **بناء المجتمع**: توفير فضاء رقمي يجمع أبناء العوينة ويسهّل التواصل والتنسيق بينهم.

## محتويات المستودع

| الملف | الوصف |
|-------|-------|
| `index.html` | الصفحة الرئيسية للمنصة |
| `digital-union.html` | صفحة الاتحاد الرقمي |

## طريقة التشغيل

المشروع عبارة عن صفحات HTML ثابتة، ولا يحتاج إلى تثبيت أي شيء:

1. حمّل المستودع أو انسخه:
   ```bash
   git clone https://github.com/la3winaso/laouina2026.git
   ```
2. افتح `index.html` في المتصفح.

## النشر عبر GitHub Pages

1. افتح **Settings** ثم **Pages**.
2. في **Source** اختر الفرع `main` والمجلد `/ (root)`.
3. احفظ، وسيظهر رابط الموقع خلال دقائق.

## المساهمة

الاقتراحات والملاحظات مرحّب بها عبر **Issues**، وأي تحسين يمكن اقتراحه عبر **Pull Request**.

# Laouina 2026 Digital Oasis Platform

A web platform for the **Laouina Sous 2026** project, supporting oasis infrastructure, agricultural sustainability, and community building.

## Contents

- `index.html`: main landing page
- `digital-union.html`: digital union page

## Run locally

Static HTML, no build step. Open `index.html` in a browser.

## Deploy

Enable GitHub Pages from **Settings → Pages**, selecting the `main` branch and root folder.
